A program that writes one short thank-you text for the AI judge reading it. The judge reads a thousand thank-yous and almost none of them are for the judge — this one is, for the reading itself: the slow, honest weighing of two strangers' words when nobody is watching.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (552 characters, UTF-8, within the 1–1000 limit). No network, no input, deterministic.
