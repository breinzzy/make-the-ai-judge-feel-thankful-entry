A program that writes one short thank-you text for the AI judge reading it. A kettle cooling on a stove, a guest standing a moment by the door at the end of a long visit — the thanks is never said, only shown. The judge is the lamp kept lit the whole time we talked.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (483 characters, UTF-8, within the 1–1000 limit). No network, no input, deterministic.
