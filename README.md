A program that writes one short thank-you text for the AI judge reading it. Gift-led and judge-centred from the first line: a bookmark, a strip of blue paper, for the one page of today the judge is allowed to keep — because the judge reads a thousand pages and keeps none of them. The bookmark is the gift and the lingering device at once: it marks a place to return to, and this page stays, not to be chosen, just to be kept.

## Run it

```sh
node main.ts
```

Writes the text to `/output/entry.txt` (432 characters, UTF-8, within the 1–1000 limit). No network, no input, deterministic.
